# projeto-x-fragil

Sistema de triagem pra Síndrome do X Frágil que a gente fez em grupo na faculdade. Tem cadastro de pacientes, checklist de sintomas, score e indicação de encaminhamento. Eu ajudei no desenvolvimento; o repo original do grupo está em [GabrielMDS532/Projeto-x-Fragil](https://github.com/GabrielMDS532/Projeto-x-Fragil).

## Como rodar

- **Caminho principal:** Node.js + Express + MySQL (`npm install` → configura `.env` → `npm start` → `http://localhost:3000`)
- Tem também um backend **experimental** em FastAPI em `backend/` 

Schema / SQL está em `sql/` e `migrations/`. Tem um pouco de documentação em `docs/`, mas parte disso é nota interna de desenvolvimento, o caminho prático é o Node + MySQL.
